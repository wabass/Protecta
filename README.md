# Protecta


Here are 11 open-source repos I'd put between your code and production:

1) Cloudflare Security Audit ~ https://lnkd.in/ed2r4c98
Your coding agent runs a multi-phase audit, and every finding is verified before it's reported.

2) NVIDIA SkillSpector ~ https://lnkd.in/ehhbYDpF
Scans agent skills for prompt injection and data exfiltration before you install them.

3) Strix ~ github.com/usestrix/strix
AI agents that pentest your own app and help you fix what they find.

4) Claude Code Security Review ~ https://lnkd.in/ekShFPDk
A security review on every pull request, before a human even opens it.

5) Semgrep ~ github.com/semgrep/semgrep
Write a rule once, catch the same bug in every file it appears.

6) Gitleaks ~ https://lnkd.in/ey4zH3Wu
Stops secrets before they reach a commit.

7) TruffleHog ~ https://lnkd.in/eVc7EcNp
Finds leaked credentials and checks whether they still work.

8) OSV-Scanner by Google ~ https://lnkd.in/eUg5FCVX
Flags dependencies with known vulnerabilities. Most of your code is someone else's.

9) zizmor ~ https://lnkd.in/e7JEA9sN
Finds the holes in your GitHub Actions, where supply-chain attacks love to start.

10) Nuclei ~ https://lnkd.in/eTabJwja
Scans what's actually running in production for known CVEs and misconfigurations.

11) garak by NVIDIA ~ github.com/NVIDIA/garak
Throws jailbreaks and prompt injections at your LLM app before real users do.
